# Passphrase Generator

A simple passphrase generator.

A single HTML file, making passphrases (between 1 and 10 words per passphrase, and between 1 and 100 lines) by combining random selections of 999 words stored in a javascript array.

The passphrases which are generated are probably completely insecure and also the code used to generate them is probably totally flawed.

For proper passphrase generators which have been written by capable developers not an inept hobbyist, it's probably worth checking other repositories on Github here:

https://github.com/topics/passphrase-generator

Also, as stated on the [demo](https://atoponce.github.io/webpassgen/) for the [webpassgen](https://github.com/atoponce/webpassgen) repository:

> Never trust online password generators, including this one... For best security, use the generator that ships with your password manager.

> For demonstration purposes only. It is not logging passwords.

## Formatting options

### Case Options
- Lower Case
- Upper Case
- Title Case
- Mixed Case

### Word Split
- None
- Space
- Dash
- Underscore
- Number
- Symbol
- Numbers and Symbols

### Letters
- Original
- Shuffle
- Reverse
