# Passphrase Generator

A simple passphrase generator.

A single HTML file, making passphrases (between 1 and 10 words per passphrase, and between 1 and 100 lines) by combining random selections of 999 words stored in a javascript array.

## Formatting options

### Case Options
- Lower Case
- Upper Case
- Title Case
- Mixed Case

### Word Split
- None
- Space
- Dash
- Underscore
- Number
- Symbol
- Numbers and Symbols

### Letters
- Original
- Shuffle
- Reverse
